# Contributing to Tropa

Tropa is a fork of [hiddify/hiddify-app](https://github.com/hiddify/hiddify-app). Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).

- Search [existing issues](https://github.com/andybeg/tropa/issues) first.
- Open new issues on this repository.
- Do not rename `hiddify-core` protocol names (gRPC, protobuf, `com.hiddify.core`). They must match the core.
- Flutter version is pinned in `pubspec.yaml`.
